## Run

```sh
python3 main.py
```

`main.py` writes the entry to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-output python3 main.py
```

The entry is validated as non-whitespace text of at most 200 characters before it is written.
